# Theju's Little Recovery Corner — Reference Build

This version is intentionally based on the supplied 10-panel visual reference.

The 10 illustrated panels are used as the visual artwork, while navigation, the heart game,
random prescription messages, smile-card interactions, progress, and restart are real HTML/JS.

Flow:
1 Welcome
2 Hey Theju / rest
3 Prescription
4 Catch the Hearts
5 Game result
6 If I were there
7 Need a Little Smile
8 Night/rest
9 Good girl
10 Final sunset

Open index.html directly, or run:
python -m http.server 8000
